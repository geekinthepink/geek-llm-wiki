# 罗福莉

## 概述

罗福莉是人工智能研究员，曾供职阿里达摩院、DeepSeek，访谈发布时为小米大模型团队负责人，主导 MiMo-V2 系列模型。她在《独家对话罗福莉：AI范式已然巨变！》中系统讨论了 [[openclaw]]、Agent 后训练、1T 基座模型、算力分配和组织形态变化。

## 关键观点

- 大模型竞争从 Pre-train 主导的 Chat 时代，转向 Post-train 主导的 Agent 时代。
- 国内顶尖团队在 Pre-train 上的代差缩小，下一阶段赛点是 [[agent-post-training-paradigm]] 中的 RL scaling。
- Agent 框架与模型能力会相互改造，形成 [[agent-framework-model-coevolution]]。
- Skills 是人向 Agent 系统贡献业务逻辑、执行规范和组织经验的重要方式。
- 组织要能容忍模糊性，鼓励密集试错和群体智能，而不是过早用管理流程压制探索。

## 与其他实体的关系

- 与 [[mimo]]：罗福莉在访谈中以 MiMo-V2 / MiMo-V2-Pro 为背景讨论模型训练和 Agent 能力追赶。
- 与 [[openclaw]]：OpenClaw 是触发她重新判断 Agent 范式的重要框架。
- 与 [[claude-code]]：访谈多次对比 Claude Code 和 OpenClaw 的框架差异。
